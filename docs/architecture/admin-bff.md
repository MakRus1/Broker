# Admin BFF

Admin BFF обслуживает административный React-клиент. Он адаптирует HTTP-контракты
сервисов, но не хранит организации, настройки, переводы и назначения прав.

## Компоненты

`AdminSessionComponent` собирает данные текущей административной сессии: проверенную
личность и CSRF из браузерной middleware, актуальные платформенные права из Organizations.
Права запрашиваются при каждом чтении сессии и не кэшируются в компоненте.

`platform::browser::Sessions` управляет входом, обновлением токенов и выходом.
Middleware `browser-session` проверяет cookie и CSRF до разбора тела запроса.
Рефакторинг не меняет этот порядок и не добавляет собственных проверок доступа:
сервисы-владельцы по-прежнему проверяют разрешения на операции и редакции объектов.

## HTTP-адаптеры и конвертеры

Простые прокси остаются в `src/views`: конкретный типизированный вызов сервиса,
передача bearer-токена и преобразование результата. Дополнительных компонентов,
повторяющих каждый метод клиента, нет.

`src/converters` содержит преобразования организаций, конфигов, продаж, транспортных
точек, курсоров и каталогов локализации. Каталоги переводятся непосредственно между
типами, без сериализации DTO в JSON и повторного парсинга. Произвольные значения
динамических конфигов остаются JSON, поскольку это часть их контракта.

HTTP-схемы находятся в `docs/api`, общие модели — в `docs/components`.
Экспорт в `schemas/services/admin_bff` обновляется кодогенератором.
