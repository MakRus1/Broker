# Компоненты Contracts

HTTP-ручки вызывают компоненты userver и формируют ответы. Компоненты не зависят
от DTO ручек или общего ResolveDeps и получают необходимые зависимости через
ComponentContext.

| Компонент | Ответственность |
| --- | --- |
| ContractsComponent | Чтение и сохранение договоров, проверка сторон и банковских счетов, реестр, фильтры, выделение номера и запись истории |
| NumberingComponent | Чтение и изменение настроек нумерации с проверкой администратора организации |

Проверки и нормализация входных данных находятся в contracts.cpp. Чистые
преобразования моделей PostgreSQL ↔ API находятся в converters/contracts.hpp
и converters/numbering.hpp. Метаданные реестра вынесены в registry/fields.hpp. В helpers
остаётся общий разбор настроек нумерации, который нужен обоим компонентам;
результат PostgreSQL читается в NumberingRow вместо tuple.

Проверки сторон и банковских счетов выполняются до транзакции записи. Выделение
номера, сохранение договора и история фиксируются одной транзакцией. Реестр
сохраняет read-only транзакцию для SET LOCAL и курсорную пагинацию. Права,
SQL, миграции, правила валидации и конфликты редакций сохранены.

Запросы фильтров и обновления нумерации получили именованные схемы вместо
анонимных DTO. Развёрнутые контракты всех шести операций совпадают с исходными.
Регрессионная проверка — полный testsuite Contracts, включая права, стороны,
банковские счета, фильтры, пагинацию, нумерацию и конфликты редакций.
