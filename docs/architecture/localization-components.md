# Компоненты Localization

| Компонент | Ответственность и зависимости |
| --- | --- |
| CatalogComponent | Чтение опубликованных переводов организации и публичных переводов входа; PostgreSQL и клиент Organizations |
| EditorComponent | Снимок редактора, сохранение черновика, проверка версии и публикация; PostgreSQL |
| SourcesComponent | Регистрация исходных текстов, проверка языков и неизменности параметров существующего ключа; PostgreSQL |

HTTP-ручки принимают запросы и формируют ответы, компоненты получают только свои
зависимости из ComponentContext. Запросам редактора и каталога даны имена в OpenAPI,
их JSON-контракты не меняются. Чистые преобразования каталогов и строк PostgreSQL
находятся в converters. В helpers остаётся общее извлечение параметров перевода.

В редакторе tuple заменены именованными структурами строк состояния и каталогов.
Чтение редактора сохраняет repeatable read; сохранение и публикация блокируют
редактируемый каталог, сверяют версию и возвращают состояние из той же транзакции.
Перед публикацией черновик заново проверяется по актуальным исходным текстам.
Общие и организационные переводы сохраняют прежнее наследование; переводы входа
нельзя переопределить для организации.

Регистрация исходных текстов сохраняет блокировку, проверку ru/en, ограничение
объёма и запрет изменения параметров существующего ключа. Чтение организационного
каталога проверяет членство через Organizations; публичная ручка отдаёт только
переводы входа. Авторизация редактора и служебной регистрации остаётся в middleware.
SQL, миграции и бизнесовые правила не меняются.

Проверка — полный testsuite Localization: доступ, публичный каталог, наследование,
черновики, конфликты версий, публикация и регистрация исходных текстов.
