# Общий справочник железнодорожных станций

Для MVP справочник ведётся вручную в разделе «Станции» административного интерфейса.
Он общий для всех организаций. Владелец данных — Transport Locations (`transport_locations`). Доступ к административным операциям требует корневую роль `platform.admin`,
как и управление общими организациями;
администратор отдельной организации не может менять общий справочник.

Карточка содержит название, двухбуквенный код страны и шестизначный код ЕСР.
Код хранится строкой с сохранением ведущих нулей. В MVP ЕСР идентифицирует запись
и не меняется при редактировании. Это покрывает станции системы ЕСР, включая
международные маршруты, но не является мировым справочником станций.
Перед подключением станций без ЕСР потребуются отдельный ID и необязательные
коды разных систем. Не следует записывать в ЕСР произвольные иностранные коды.

Поиск в перевозке использует локальную БД и возвращает до 20 совпадений по названию
или коду. Административный список имеет поиск и курсорную пагинацию по 50 записей.
Редактирование названия не переписывает исторические снимки маршрутов.
Архивирование исключает запись из выбора. Сохранённая станция остаётся видна в
маршруте; повторное сохранение неизменённого снимка разрешено. Физического удаления нет.
Повторное сохранение записи по ЕСР возвращает её из архива.

Внешние поставщики, автоматическая синхронизация и импорт OSM в MVP не подключены.
Пробные выгрузки Казахстана и Беларуси показали неполноту тегов, дубли и некорректные
значения ЕСР. Не следует считать их подтверждённым грузовым реестром.


## Станции в маршруте

ЖД-участки хранят выбранные станции только в `rail.origin_station` и
`rail.destination_station`. Общие `origin`/`destination` для ЖД не используются;
старые свободные пункты очищаются в миграции. Заголовки, реестр и редактор
вычисляют подписи по станциям, не сохраняя вторую копию названия и страны.

Загрузка справочника отделена от правил: `helpers/railway_stations.hpp` получает
активные станции одним пакетным запросом в Transport Locations по уникальным кодам; `helpers/converters.hpp`
преобразует строки БД; `domain/rail.cpp` проверяет станции и сохранённые снимки
архивных записей, не обращаясь к БД и не принимая зависимости сервиса.
