# Компонент User Preferences

PreferencesComponent отвечает за чтение и сохранение личных настроек. Зависимости —
PostgreSQL и клиент Organizations, полученные напрямую из ComponentContext.
HTTP-ручки передают именованные модели запросов и формируют ответы; чистые
преобразования строк PostgreSQL находятся в converters/preferences.hpp.

Представления реестров, избранное и другие настройки используют единый механизм
хранения ключа и значения. Сервис не интерпретирует их содержимое, поэтому отдельных
компонентов для каждого вида настроек нет.

Сохранены проверка членства в организации перед каждой операцией, получение issuer
и subject из проверенного токена, изоляция настроек пользователя и организации,
ограничение значения в 64 КиБ и атомарная проверка ожидаемой редакции при записи.
Конфликт изменения возвращает прежний код preference_changed. SQL и миграции
не меняются, JSON-контракты обеих ручек сохранены.

Проверки — полный testsuite User Preferences, сборки и testsuite зависимых BFF,
проверки генерации, форматирования и инструментов.
