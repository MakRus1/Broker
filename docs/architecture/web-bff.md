# Пользовательский BFF

Web BFF принимает запросы браузера и адаптирует контракты сервисов для Web.
Бизнесовые правила и данные остаются у сервисов-владельцев. Большинство ручек
выполняют один типизированный вызов клиента и преобразуют ответ; отдельный
компонент-обёртка для каждой такой ручки не нужен.

## Компоненты и зависимости

- `platform::browser::Sessions` владеет браузерными сессиями и обновлением токенов.
  Middleware `BrowserSessionFactory` проверяет сессию и CSRF. Login, callback,
  logout и cookie продолжают использовать общую библиотеку браузерного доступа.
- `PreferencesComponent` отвечает за личные и ролевые настройки рабочего
  пространства. При чтении он объединяет настройки из User Preferences с
  исходными видами ролей из Organizations. Сохранение отправляется соответствующему
  владельцу; проверки членства, прав и редакций остаются в этих сервисах.
- `Cities` выполняет поиск городов через внешний справочник.
- `PublicCatalogCors` задаёт CORS для публичного каталога переводов.
- Сгенерированные клиентские компоненты отвечают за HTTP-вызовы сервисов,
  проверку контрактов и динамические HTTP-настройки.

Токен текущей сессии передаётся сервисам без изменения. Компонент настроек не
хранит персональные данные в общем состоянии и не кеширует ответы между
пользователями. Состав и порядок обращений к сервисам при выделении компонента
сохраняются.

## Преобразование контрактов

В `src/converters` находятся преобразования моделей и метаданных реестров.
Продажи используют явные типизированные преобразования запросов и ответов,
включая маршруты, вложенные цены, котировки и историю. Промежуточная сериализация
модели в JSON с последующим парсингом другой модели не используется.

Произвольный JSON остаётся там, где он является частью контракта: значения
пользовательских настроек и запрос внешнему сервису городов. Это не преобразование
одного DTO в другой.

HTTP-ручки сохраняют HTTP-детали: извлечение текущей сессии, cookie и формирование
ответа. Прямые адаптеры сервисов остаются в ручках; составные операции настроек
делегируются компоненту. URL, JSON-контракты, права и поведение сессий при
рефакторинге не меняются.
