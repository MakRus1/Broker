# Развитие интерфейса

## Визуальный фундамент

Светлая, тёмная и системная темы; семантическая палитра для текста, поверхностей,
границ и состояний. Личный выбор сохраняется через User Preferences. Web передаёт текущую тему на форму входа Keycloak; выбранное оформление сохраняется
на всех шагах авторизации. При прямом входе без выбора используется системная тема.

В админке используется та же палитра и переключатель темы; выбор пока хранится
в браузере. Платформенные сессии не требуют выбора организации, поэтому их
настройки нельзя автоматически привязать к существующему организационному хранилищу.

## Следующие этапы

- Русский и английский языки, ручной выбор языка и изменяемые без релиза переводы.
- Терминология организации: например, «поставки» и «букинги».
- Проработка основных пользовательских сценариев и общий редизайн.
- Контекстные подсказки, полезные пустые состояния, интерактивные инструкции по
  сценариям и знакомство с новыми возможностями. Их можно пропустить, закрыть и
  повторно открыть из помощи. Прогресс хранится в личных настройках; повторный
  показ уже пройденного исключается. Разрабатывать после стабилизации сценариев.
- Небольшие анимации переходов и обратной связи с поддержкой reduced motion.

## Проактивная помощь

Подсказка возле вопросика показывается один раз для просмотра карточек и один раз
для редактора, суммарно для всех форм и их вкладок в личных настройках организации.
Показ отмечается сразу, поэтому быстрый уход с вкладки не вызывает повторения.
Ранее просмотренные подсказки учитываются. Плашка закрывается крестиком,
при открытии помощи или автоматически через 10 секунд. Сам вопросик и инструкции
остаются доступны независимо от показа плашки.
