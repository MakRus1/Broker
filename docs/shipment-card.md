# Карточка поставки: первый этап

Поставка содержит номер, дату поставки, клиента, получателя, логиста, описание груза,
статус, Incoterms, условия перевозки, загрузку, город, страну и адрес доставки.
Дата поставки — дата регистрации с привычным бизнес-названием. Новая форма подставляет
сегодняшнюю дату в часовом поясе браузера; серверный fallback для старых клиентов — UTC.
Будущие даты разрешены, нижняя граница 1900 года проверяется приложением, а не CHECK в БД.

Номер хранится единственным строковым полем и уникален внутри организации. Внутренний UUID
от него не зависит. Шаблон поддерживает `{sequence}`, `{yyyy}`, `{yy}`, `{mm}`, `{dd}`.
Счётчик организации может быть сквозным или годовым; период выбирается по дате поставки.
Его изменение атомарно с созданием поставки и записью идемпотентного результата. Изменение
шаблона не переименовывает созданные поставки. Ручной номер не расходует счётчик;
занятый номер возвращает 409 и требует выбора другого номера либо исправления шаблона.
Существующие номера `S-N` при миграции сохраняются, второго числового поля больше нет.

## Справочники и подсказки

`shipment_dictionary_values` — явный каталог кодов и названий. API
`/api/v1/shipments/dictionaries` обслуживает форму; та же таблица используется для
серверной валидации. Стартовые значения заданы миграцией, списки не дублируются в C++ и TS.
Incoterms основаны на [перечне ICC для редакции 2020](https://2go.iccwbo.org/explore-our-products/ebooks/incoterms-2020-practical-free-wallchart.html).

Сохранённые описания груза попадают в подсказки своей организации. Удаление подсказки
не меняет поставки. Скрытое значение не появляется вновь при очередном сохранении старой
поставки. Для поиска используется отдельное Unicode-представление в нижнем регистре;
исходный текст сохраняется без изменения регистра и не зависит от локали PostgreSQL.
Подсказки загружаются только при работе с полем, с задержкой 250 мс и отменой устаревшего
запроса. Ответ ограничен 20 совпадениями, выпадающий список ограничен по высоте.

## Маршрут

Поставка хранит упорядоченные участки `route_segments`: UUID участка и код типа.
Идентификатор остаётся прежним при перестановке. Дублирующиеся UUID запрещены, одинаковые
типы допустимы. Общие и индивидуальные поля участков, их связь с детальным маршрутом
существующих перевозок и правила изменения при наличии фактов — следующий этап.

## Организационные настройки

На этом этапе read-only API `/api/v1/shipments/settings` читает типизированный
`SHIPMENT_SETTINGS` с контекстом организации и клиента. Он задаёт шаблон номера,
сброс счётчика, доступные статусы и типы участков, плановые контейнеры и их типы.
Само включение интерфейса не заменяет проверку на сервере: запрещённый тип контейнера
или участка отклоняется. Скрытие блока не удаляет уже записанные позиции.

Это ещё не интерфейс бизнес-настроек в админке организации. Граница между настройками
платформы, доступными администратору организации параметрами и настройками клиента
требует отдельного решения. Параметры доступа и состав купленных модулей не должны
изменяться администратором организации через редактирование её рабочих настроек.

Закрепление логиста за клиентом и поиск городов с автоматическим определением страны
ещё не подключены к собственным справочникам. Текущие поля логиста, города и страны
сохраняются в карточке; `default_logist` — временная точка подключения значения по умолчанию.

## Рабочие вкладки

Реестр и каждая карточка открываются отдельно внутри приложения. Несколько новых поставок
имеют разные адреса и черновики. Переключение скрывает страницу без размонтирования;
сохраняются поля и состояние вложенных вкладок. Закрытие с изменениями требует
подтверждения, после подтверждения черновик удаляется. Незакрытая изменённая карточка
сохраняет черновик в sessionStorage своей браузерной вкладки. Проверка редакции на сервере
не позволяет молча перезаписать параллельное изменение.

При обновлении релиза требуется применить миграции и запустить сервисы с контрактом
`shipment_v2` и входным типом `shipment_data_v1`; прежние SQL-запросы, ожидающие числовой номер, больше не подходят.
