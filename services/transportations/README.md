# Transportations

Фактические перевозки, данные участков и факты исполнения. Структура маршрута наследуется из поставки. Ручное создание и получение команд создания идемпотентны.

Описание API, авторизации, запуска и ограничений: [первый серверный срез](../../docs/architecture/logistics-first-slice.md).

Генерация из каталога сервиса: `make gen`. Проверка из корня: `make check-gen-all`.

Владение данными, ручное создание и защита участков: [перевозки и маршрут поставки](../../docs/architecture/transportation-basics.md).
